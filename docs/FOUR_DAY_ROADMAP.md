# 中山大学 SYSU：四天协作路线

## 协作规则

每一步都按“理解目标 → 你输入代码 → 运行观察 → 共同排错 → Git检查点”推进。参考成品保存在 `codex/reference-v1`，学习开发位于 `codex/four-day-workshop`。

## Day 1：视觉系统、启动动画与章节转场

- 理解React组件、状态、ref与GSAP时间轴。
- 完成“大山中学 → 中山大学”5秒启动动画。
- 抽象1.2–1.8秒四格章节转场。
- 接入导航、滚动锁定、快速点击取消和重播按钮。
- 验收：变化清晰可见，每章仅触发一次，移动端和减少动画模式可用。

## Day 2：首屏与3D书籍档案

- 制作SYSU原创字标和全屏首屏舞台。
- 学习perspective、preserve-3d和transform-origin。
- 制作书脊、封面、封底与6层纸页。
- 编排飞入、180°开书、纸页弯曲、风吹翻页与反向收书。
- 验收：连续点击不乱页，键盘和触屏可操作。

## Day 3：内容、Flask寄语与真实校徽

- 扩充12个校史节点、文化档案、11项学科和五校园内容。
- 学习Flask路由、SQLite模型、登录会话和CSRF。
- 从官方校徽透明蒙版采样2000–3000个目标点。
- 第40条寄语触发扩散、扫描与真实校徽聚合。
- 验收：一人一条，刷新后数据仍在，聚合结果是校徽图形而非文字。

## Day 4：诗卷、全站动效统一与交付

- 制作诗封、宣纸展开、楷体显墨、竖排诗句与朱印。
- 统一进入、退出、点击、悬停和章节转场节奏。
- 完成手机端、错误状态和减少动画模式。
- 完成构建、全流程测试、资料来源与README。
