# 中大狮加载动画分镜

参考资料位于 `docs/references/`，只用于分析动作与构图，不作为最终网站资产发布。

## 角色设计

- 原型：中山大学校园常见的绿色陶瓷醒狮。
- 造型：低重心、圆润四足、绿色琉璃质感、鬃毛包含海棠窗与木棉纹样。
- 识别：额头使用原创“SYSU”或“中”字图形，不能直接套用邦布轮廓。
- 输出：后续绘制一张透明角色分层图或6–8帧奔跑序列，放入 `public/mascot/`。

## 首次启动时间轴（5秒）

1. `0.0–0.8s`：中大狮从右下角原地小跑，四足交替、身体上下弹跳。
2. `0.8–1.8s`：旁侧稳定显示“大山中学”，速度线随脚步闪动。
3. `1.8–2.5s`：中大狮加速并前倾，扫描线锁定四个字。
4. `2.5–3.6s`：中大狮向前冲刺，四格受冲击错位，重排为“中山大学”。
5. `3.6–4.4s`：中大狮刹停回头，最终字样清晰停留。
6. `4.4–5.0s`：角色与字标一同缩入首屏，页面开启。

## 章节短转场（1.55秒）

- 中大狮在右下角连续跑动。
- 四格显示章节编号与名称，例如“0、2、文、化”。
- 遮罩关闭时加速，章节出现时减速离场。
- 已读章节在尾部闪出绿色 `ARCHIVE READ`。

## 动画验收

- 奔跑不是整张图片左右平移：四足、身体、鬃毛和尾巴必须分层运动。
- 落脚时身体下沉，腾空时身体上升，速度线与落脚节奏一致。
- “大山中学”至少完整停留1秒，“中山大学”至少完整停留0.8秒。
- 每个章节转场复用同一个组件，但文字、速度和背景方向可以变化。
- 移动端保留角色奔跑，减少速度线数量；减少动态效果模式显示静态中大狮。
